# 🍬 グミレポ

グミ専用レポートブログ。食べたグミを写真・評価・感想で記録するWebアプリです。

## 機能

- グミレポの投稿（写真・名前・味と弾力の5段階評価・感想）
- ブラウザのlocalStorageに保存（ページを閉じても残る）
- カードを削除
- レスポンシブ対応（スマホでも使いやすい）

## GitHub Pagesで公開する手順

1. このリポジトリを GitHub に push する
2. GitHubリポジトリの **Settings → Pages** を開く
3. Source を `Deploy from a branch` に設定
4. Branch を `main`（または `master`）、フォルダを `/ (root)` に設定して **Save**
5. 数分後に `https://あなたのユーザー名.github.io/リポジトリ名/` で公開される

## ファイル構成

```

```
